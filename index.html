How it works

  1. Question: “What’s the nearest hospital to this location?”
  2. Geocode / snap: the location is matched to the nearest node on the OpenStreetMap drivable road network.
  3. Network routing: Dijkstra shortest paths over real roads and bridges, weighted by travel time (OSM speed limits, with typical speeds filled in where they are missing).
  4. Rank by travel time: every candidate hospital is ranked by drive minutes, not by straight-line miles.
  5. Model explains: the LLM agent calls these GIS tools, then reports the answer in plain language and says why the straight-line pick is wrong (e.g. the river is between you and it).

Times are free-flow estimates with no live traffic. This is a methodology demo, not medical or navigation advice. Hospitals are named OSM amenity=hospital features in Duval County, limited to general acute-care hospitals; UF Health Jacksonville (downtown) is mapped in OSM as a relation, so it was added manually from its OSM/Nominatim location.

Map data © OpenStreetMap contributors (ODbL), road network from the Geofabrik Florida extract. Live mode: routing by the OSRM public demo server (OSM data, free-flow, no traffic); geocoding by Nominatim/OpenStreetMap. Built by GeoKnight GIS with AI assistance.
